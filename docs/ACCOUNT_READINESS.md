# Account readiness

project owner's development machine; deadlines follow the gate-aligned implementation
sequence (decision D16). Evidence never includes a token, key, connection string or secret
suffix. An environment-variable check records only whether a name is set, never its value.
No account is marked ready without such evidence.

applies to the sponsor accounts, whose conditional work is Sprint 8 under D16; it says
