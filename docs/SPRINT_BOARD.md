# Sprint board

Sprints 0 to 9 for ETHOnline 2026, cut on 4 September 2026 against the official event
schedule (D14) and the gate-aligned implementation sequence (D16). All times are
America/Toronto. The controls in the tables below are fixed. A sprint closes when its gate
passes; the calendar is cut so that every gate lands before the submission deadline.

## Standing rules

- Sponsor integrations (Sprint 8) begin only after the Graph release candidate passes and
  only if the time budget allows.
- No dashboard polish while live Graph access, clean MCP installation or evidence provenance
  is broken.
- Claude implements on sprint branches. Codex independently reviews diffs, installs locked
  dependencies when appropriate, and reruns verification. Neither agent merges to `main`
  without the project owner's instruction. Each sprint begins only after the Codex audit of
  the previous sprint is answered.
