## Objective and boundary

The current feed tab of the workbook `Cyberattack Sunday - RSS Intake` reaches PostgreSQL on
Railway Hobby by one command, idempotently, with the provenance the CSV importer records today.

In scope: the Railway Hobby upgrade; the service account and single-file share; live inventory
and timestamp report; a worker command that imports the current feed tab as a batch with origin
`live`; the weekly import runbook; transcription of plan decisions P-1 to P-6 into
`docs/DECISIONS.md`.

Out of scope: historical weekly tabs; classification; any dashboard change; any change to the
CSV importer's behaviour.

## Acceptance

- From a clean checkout with `GOOGLE_APPLICATION_CREDENTIALS`, `GOOGLE_SHEETS_SPREADSHEET_ID`
  and `DATABASE_URL` set, one command creates a batch from the current feed tab with origin
  `live`.
- The same command a second time creates no new rows and reports the idempotent outcome.
- The command refuses a workbook whose digest is not the pinned one, with a fixed message.
- `DATABASE_URL`, the spreadsheet identifier and the credential path appear in no output.
- The database size after import is recorded and is under 5 GB, with the headroom stated.
