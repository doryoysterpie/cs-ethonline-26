## Objective and boundary

The nine lists D49 names outside CAS-011's three consumers take their set from the
prohibited-text rule in `@cas/contracts`, and each keeps its own action:

| List                                         | Action today                                                        |
| -------------------------------------------- | ------------------------------------------------------------------- |
| `apps/dashboard/src/server/display.ts`       | escapes, in the dashboard's display of stored text                  |
| `apps/dashboard/src/server/dal/mutate.ts`    | refuses, when a draft, round-up or article body is saved            |
| `packages/mcp-server/src/safety/text.ts`     | escapes, in the MCP server's output                                 |
| `apps/worker/src/hygiene/scan.ts`            | scans source files                                                  |
| `apps/worker/src/editorial/display.ts`       | escapes in the worker's output; refuses in a review note or a claim |
| `apps/dashboard/src/server/input.ts`         | refuses, in the dashboard's bounded inputs                          |
| `apps/dashboard/src/server/auth/password.ts` | refuses, in a password                                              |
| `packages/graph-evidence/src/display.ts`     | escapes, in that package's output                                   |
| `packages/sheets-intake/src/display.ts`      | escapes, in that package's output                                   |

Every escape takes one form, `\u{XXXX}`, and a line about a character adds its Unicode name
from a generated table. Stored text, the three consumers of CAS-011 and the rule itself do not
change; migration 0024 adds each revision's record of what its save removed, as numbers. Until
this unit lands, no new list: any new consumer imports the predicate from `@cas/contracts`.
